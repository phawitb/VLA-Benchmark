Manual Setup Guide
GPU Server Requirements:
1. SSH access — key-based or password
2. tmux — sudo apt install -y tmux
3. Conda — install Miniforge:
wget https://github.com/conda-forge/miniforge/releases/latest/download/Miniforge3-Linux-x86_64.sh
bash Miniforge3-Linux-x86_64.sh
# restart shell after install
4. Conda env + LeRobot:
conda create -n lerobot python=3.12 -y
conda activate lerobot
pip install lerobot
5. Working Directory:
mkdir -p ~/vla_benchmark_ws/logs
6. HuggingFace — token is auto-set from Setup > Hugging Face (no manual login needed)
Or click Fix Environment to auto-install tmux, conda env, and lerobot.
